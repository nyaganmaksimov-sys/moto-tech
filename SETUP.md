# MOTO TECH Service — прототип 0.1

## Локальный запуск

Требуется Python 3.10+.

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# Linux: source .venv/bin/activate
pip install -r requirements.txt
uvicorn app:app --host 127.0.0.1 --port 8000
```

Открыть http://127.0.0.1:8000. Документация API: http://127.0.0.1:8000/docs.

База SQLite `moto.db` создаётся при первом запуске. Цены примеров условные и требуют согласования с MOTO TECH.

## Важные ограничения

Это демонстрационный прототип. Пока отсутствуют аутентификация, разграничение ролей, комплексный склад, полноценная себестоимость, печатные документы и защита персональных данных для промышленного использования. **Не публиковать приложение в интернете и не вводить реальные данные клиентов до внедрения мер безопасности**. Текущая отметка согласования не подтверждает волеизъявление клиента. Оплаты только регистрируются в учёте и не формируют фискальный чек.
