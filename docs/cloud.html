Тестовые данные

Демоданные отмечены отдельно. Очистка удаляет только тестовые записи в облачной базе, реальные данные не затрагиваются.

Мой профиль

Должность и доступ меняются только руководителями.

Новая приёмка

Механики могут принимать технику на ремонт и хранение. Изменения действующих заказов пока доступны только через отдельные защищённые процедуры.

Тестовый рабочий кабинет

Данные читаются из PostgreSQL с проверкой прав на сервере. Изменение заказов пока заблокировано до внедрения безопасного PIN.
