Вход сотрудника

Аккаунты создаются руководителем проекта. Самостоятельная регистрация отключена в интерфейсе.

Выполните вход по личному логину и паролю на отдельной странице.

Перейти к входу

Первый вход: смена PIN

Ваш стартовый PIN — 0000. Придумайте личный код из 4–6 цифр. До смены PIN рабочие разделы скрыты.

Единая облачная система MOTO TECH

Данные общие для всех сотрудников и хранятся в Supabase. Доступ к разделам определяется ролью. Функции, не подключённые к облачной базе, пока не включены.

Мой профиль

Должность и доступ меняются только руководителями.

Новая приёмка

Механики могут принимать технику на ремонт и хранение. Изменения действующих заказов пока доступны только через отдельные защищённые процедуры.

Общие рабочие данные

Данные читаются из PostgreSQL с проверкой прав на сервере. Изменение заказов пока заблокировано до внедрения безопасного PIN.
