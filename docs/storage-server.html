Интеграция с 1С

Подготовка обмена. Передача данных отключена до настройки конфигурации 1С.

Для подключения понадобятся версия конфигурации, URL HTTPS опубликованного сервиса, учётная запись обмена с минимальными правами и согласование состава выгружаемых документов. Пароли и токены не вводятся в эту форму.
