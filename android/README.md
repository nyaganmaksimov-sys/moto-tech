# MOTO TECH Android 0.1.0

Тестовый Android-клиент открывает https://nyaganmaksimov-sys.github.io/moto-tech/workspace.html.

GitHub Actions -> Android test APK -> Artifacts (debug APK). Единые серверные данные, авторизация и права из веб-версии.

Это стартовая оболочка с поддержкой системного выбора фото и файлов. Нет автономного редактирования заказов и подтверждённого офлайн-режима; необходима интеграция в актуальный frontend и backend с защитой повторных операций. Проверить камеру, фото ПТС, документы и вход на настоящем телефоне. Debug APK не является подписанным релизом.
