# Обновления Android MOTO TECH

Версия Android 0.2.0 включает проверку последнего GitHub Release при запуске и кнопку «Проверить обновления». Приложение проверяет версию, предлагает скачать APK и вызывает системный установщик Android после отдельного подтверждения. Приложение **не удаляется**, если пакет и сертификат подписи совпадают и versionCode выше.

## Выпуск обновлений
1. Сформировать ОДИН постоянный release keystore в защищённом хранилище; никогда не коммитить его в репозиторий.
2. Настроить в GitHub Actions секреты для keystore и паролей, собрать и подписать релизный APK.
3. Опубликовать GitHub Release с тегом v0.2.1 или выше и APK-артефактом, в имени которого есть android, например MOTO-TECH-android-0.2.1.apk.
4. Все следующие релизы подписывать тем же сертификатом и увеличивать versionCode.
5. Проверить тест на одном Android: установка 0.2.0 -> выпуск 0.2.1 -> уведомление -> загрузка -> установка поверх без потери данных.
6. Если установленный 0.1.x debug APK использовал другой ключ, Android отклонит установку поверх него. Для перехода потребуется миграция или переустановка с сохранением важных данных на сервере.

Обычные изменения сайта GitHub Pages не требуют APK. APK обновляется только при изменениях Android-оболочки. Проверка доступна только при интернете.

**Текущий статус:** логика уведомления, загрузки и вызова системного установщика реализована, но выпуск подписанных релизов ещё не настроен. Автоматическая бесшумная установка запрещена Android; пользователь подтверждает её в системном окне.
