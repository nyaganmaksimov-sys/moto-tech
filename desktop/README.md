# MOTO TECH для Windows — тестовая оболочка

Эта сборка открывает **существующую веб-систему**, используя отдельное окно Electron без адресной строки. Она не заменяет сервер и Supabase и не добавляет демо-данные.

1. Для тестовой сборки: `cd desktop && npm install && npm run dist:win` на Windows с Node.js 22.
2. Установщик NSIS будет в `desktop/dist/`.
3. При первом запуске приложение автоматически открывает https://nyaganmaksimov-sys.github.io/moto-tech/workspace.html. Экран ввода адреса появляется только при отсутствии или ошибке настройки.
4. Входите под обычным логином. Веб-приложение и его права, PIN, данные и оповещения остаются серверными.

**Ограничения:** реальный URL пока не указан, поэтому приложение не сможет открыть систему без настройки. Оформление внутри окна берётся с действующего сайта: для отображения исправленного дизайна нужно также внедрить правки в веб-версию. Сборка не запускалась и не проверялась в этой среде. Подпись установщика сертификатом ещё не настроена. Перед выпуском проверить камеру, загрузку фотографий, скачивание PDF, печать, PIN, обновление страницы, уведомления, вход и выход.

## Обновления
- Изменения веб-интерфейса публикуются на GitHub Pages и становятся доступны клиенту при следующей загрузке страницы. Никакой переустановки EXE не требуется.
- Изменения Electron выпускаются как **GitHub Release**, например `v0.2.1`. Выпуск должен включать NSIS EXE и `latest.yml`, созданные electron-builder, иначе автообновление не заработает.
- После запуска установленной версии клиент проверяет релиз. При наличии обновления предлагает скачать, затем отдельно предлагает установку и перезапуск.
- В меню MOTO TECH доступен пункт «Проверить обновления».
- Автоматическая установка без подтверждения отключена, чтобы не прерывать оформление заказов.
- Для штатного публичного выпуска нужна цифровая подпись установщика Windows и проверка обновления на двух последовательных версиях. Тестовые сборки из Artifacts не являются релизами и для них нельзя считать автообновление проверенным.
