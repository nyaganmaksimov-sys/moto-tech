# MOTO TECH — переход к единой базе

Ветка содержит **схему**, но не подключена к работающему экземпляру PostgreSQL.
Текущий сайт GitHub Pages сохраняет данные в `localStorage` одного браузера;
для совместной работы сотрудников нужен защищённый API и отдельное файловое
хранилище. Нельзя записывать персональные данные или фото в публичный GitHub.

## Сущности
- employees — роли, учётные записи и хэши паролей
- customers — клиенты
- makes, models, vehicles — марки, модели и экземпляры техники
- price_items — каталог работ и цены
- orders, order_lines — наряды, работы и запчасти
- order_photos — ссылки на приватные изображения с этапами приёмки и ремонта
- stock_items, stock_movements — склад и история движения
- payments — зарегистрированные оплаты; сами по себе они не формируют кассовый чек
- audit_log — аудит действий

## Обязательная фотофиксация
Новый заказ не должен переходить в статус `accepted` без минимум одного
файла с `stage='intake'`. Это необходимо реализовать **на сервере в одной
транзакции с созданием заказа и сохранением фото**, а не только проверкой
в браузере. Хранить фото в приватном объектном хранилище с резервными копиями.
Нужны подпись времени, автор снимка, запрет обычным сотрудникам удалять
оригинальные фото, отдельные фото дефектов и после ремонта.

## Дальнейшее внедрение
1. Утвердить среду размещения и создать PostgreSQL и приватное файловое хранилище.
2. Настроить миграции и секрет `DATABASE_URL` исключительно на сервере.
3. Реализовать регистрацию сотрудников администратором, вход и проверку ролей.
4. Подключить API с проверкой прав к форме GitHub Pages или перенести фронтенд
   на тот же сервер. Разрешить CORS только для штатного адреса.
5. Импортировать 188 позиций прайса и каталог марок/моделей.
6. Протестировать два устройства, запись заказов, фото, удаление, резервные копии.
7. Только затем переносить реальные данные и включать боевую эксплуатацию.

**Внимание:** публичная демонстрация на GitHub Pages не готова к хранению
персональных данных клиентов. Не загружайте туда фотографии клиентов,
VIN и телефоны до включения защищённого сервера.
